# План реализации

Согласованная спецификация: 2026-10-26-inline-visuals-design.md. Пользователь разрешил реализацию.

1. Общий исполняемый документ components-v1: React-компоненты из фронтенда, скомпилированная CSS приложения, SVG/Canvas API. Авторский JavaScript возвращает React-компонент; CSS вручную не требуется. Документ самодостаточный и запускается в sandbox.
2. Сохраняем роль demoBuilder как единственного нового исполнителя; visual становится совместимым входом в неё. Старые сохранённые SVG читаются прежним renderer. Отдельный промпт demoBuilder и модель kimi-coding:k3-256k/max.
3. Отдельная строка `[visual](lh-artifact:JOB_ID)` в ответе teacher задаёт вставку. Результат ищется только среди заданий текущего чата; место сохраняется в сообщении. Доставка не дублирует вставленный результат.
4. Проверить формат, разрешение модели, inline-разбор, совместимость и runtime в настоящем браузере; typecheck, build. Изменения установленного приложения и упаковку выполнять только после успешных проверок.
